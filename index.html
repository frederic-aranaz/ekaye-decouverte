Une photo est refusée « format HEIC » ?

Le HEIC est le format d'origine de beaucoup de téléphones. Les navigateurs Android ne savent pas l'ouvrir. Le réglage se fait une fois pour toutes :

Android (Samsung) — Appareil photo → ⚙ Paramètres → Formats avancés → désactiver Photos HEIF.

iPhone — Réglages → Appareil photo → Formats → Le plus compatible.

En dépannage immédiat : le bouton Prendre une photo ci-dessus donne le plus souvent du JPEG, même quand la galerie est en HEIC.
